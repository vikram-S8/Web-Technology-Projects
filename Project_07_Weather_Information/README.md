# Weather Information Website

## Project Title
Weather Information Website

## Aim
To create a simple weather information webpage.

## Objective
To demonstrate searching and displaying weather data using JavaScript without an external API.

## Description
A sample-data weather app for three cities. It intentionally uses local data so no API key or internet service is required.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- City search
- Weather cards
- Temperature, humidity and wind display
- No external API required

## How to Run
1. Open this project folder.
2. Double-click `index.html`, or open it in any modern web browser.
3. No server, database, API key, or installation is required.

## Expected Output
The selected sample city displays its weather information in a clean card.

## Conclusion
This project demonstrates practical use of HTML, CSS, and JavaScript to build a simple, responsive, functional web application suitable for a college mini project.
