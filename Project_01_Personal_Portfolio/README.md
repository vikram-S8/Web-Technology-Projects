# Personal Portfolio Website

## Project Title
Personal Portfolio Website

## Aim
To create a personal portfolio webpage.

## Objective
To present a student profile, skills, projects, and contact form in a professional layout.

## Description
A responsive portfolio website with navigation, profile sections, project cards, and a working client-side contact form.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Responsive navigation
- About, skills and project sections
- Contact form validation
- Clean responsive UI

## How to Run
1. Open this project folder.
2. Double-click `index.html`, or open it in any modern web browser.
3. No server, database, API key, or installation is required.

## Expected Output
A browser displays a professional personal portfolio and shows a confirmation after submitting the contact form.

## Conclusion
This project demonstrates practical use of HTML, CSS, and JavaScript to build a simple, responsive, functional web application suitable for a college mini project.
