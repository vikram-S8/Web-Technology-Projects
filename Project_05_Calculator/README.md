# Calculator

## Project Title
Calculator

## Aim
To create a basic web calculator.

## Objective
To perform arithmetic operations through an interactive JavaScript interface.

## Description
A responsive calculator supporting addition, subtraction, multiplication, division, percentage, decimals, clear, delete, and equals.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Arithmetic operations
- Responsive button layout
- Clear and delete controls
- Error handling

## How to Run
1. Open this project folder.
2. Double-click `index.html`, or open it in any modern web browser.
3. No server, database, API key, or installation is required.

## Expected Output
The calculator accepts numbers and operators and displays the calculated result.

## Conclusion
This project demonstrates practical use of HTML, CSS, and JavaScript to build a simple, responsive, functional web application suitable for a college mini project.
