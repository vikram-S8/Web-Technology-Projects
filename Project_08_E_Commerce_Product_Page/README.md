# E-Commerce Product Page

## Project Title
E-Commerce Product Page

## Aim
To design a product page for an online store.

## Objective
To display product details and demonstrate cart and buy-now interactions.

## Description
A responsive product page with product information, pricing, ratings, and interactive buttons.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Product details
- Price and rating
- Add to cart counter
- Buy now demo message

## How to Run
1. Open this project folder.
2. Double-click `index.html`, or open it in any modern web browser.
3. No server, database, API key, or installation is required.

## Expected Output
The product is displayed professionally and buttons provide interactive shopping feedback.

## Conclusion
This project demonstrates practical use of HTML, CSS, and JavaScript to build a simple, responsive, functional web application suitable for a college mini project.
