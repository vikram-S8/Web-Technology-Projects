# Online Food Ordering Website

## Project Title
Online Food Ordering Website

## Aim
To design a simple online food ordering interface.

## Objective
To allow users to browse sample foods, add items to a cart, and place a demo order.

## Description
A responsive food menu with local sample data and a JavaScript shopping cart.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Food menu cards
- Add-to-cart function
- Cart count and total
- Demo checkout message

## How to Run
1. Open this project folder.
2. Double-click `index.html`, or open it in any modern web browser.
3. No server, database, API key, or installation is required.

## Expected Output
Users can select food items, view the cart total, and place a simulated order.

## Conclusion
This project demonstrates practical use of HTML, CSS, and JavaScript to build a simple, responsive, functional web application suitable for a college mini project.
