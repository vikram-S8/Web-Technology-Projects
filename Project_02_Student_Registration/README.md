# Student Registration Form

## Project Title
Student Registration Form

## Aim
To build a digital student registration form.

## Objective
To collect and validate basic student details using HTML forms and JavaScript.

## Description
A client-side registration form that validates required fields and displays a successful registration message.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Student detail fields
- HTML validation
- Department and gender selection
- JavaScript success message

## How to Run
1. Open this project folder.
2. Double-click `index.html`, or open it in any modern web browser.
3. No server, database, API key, or installation is required.

## Expected Output
The user can enter details and receive a registration confirmation without a backend.

## Conclusion
This project demonstrates practical use of HTML, CSS, and JavaScript to build a simple, responsive, functional web application suitable for a college mini project.
