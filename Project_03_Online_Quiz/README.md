# Online Quiz Application

## Project Title
Online Quiz Application

## Aim
To create an interactive online quiz.

## Objective
To test basic web technology knowledge and calculate a score using JavaScript.

## Description
A five-question quiz where users select answers, move through questions, and receive a final score.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Multiple-choice questions
- Answer selection
- Score calculation
- Restart option

## How to Run
1. Open this project folder.
2. Double-click `index.html`, or open it in any modern web browser.
3. No server, database, API key, or installation is required.

## Expected Output
The quiz displays questions one at a time and shows the final score after completion.

## Conclusion
This project demonstrates practical use of HTML, CSS, and JavaScript to build a simple, responsive, functional web application suitable for a college mini project.
