# To-Do List Application

## Project Title
To-Do List Application

## Aim
To develop a simple task management application.

## Objective
To add, complete, delete, and save tasks in the browser.

## Description
A clean to-do list using JavaScript and localStorage so tasks remain after refreshing the page.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Add tasks
- Mark tasks complete
- Delete tasks
- Persistent local storage

## How to Run
1. Open this project folder.
2. Double-click `index.html`, or open it in any modern web browser.
3. No server, database, API key, or installation is required.

## Expected Output
Users can manage a personal task list and the data remains available after page refresh.

## Conclusion
This project demonstrates practical use of HTML, CSS, and JavaScript to build a simple, responsive, functional web application suitable for a college mini project.
