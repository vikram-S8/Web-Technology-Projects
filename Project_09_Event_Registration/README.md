# Event Registration Website

## Project Title
Event Registration Website

## Aim
To create an online registration page for a college event.

## Objective
To collect participant information and selected event details.

## Description
A clean event landing page with a registration form and client-side confirmation.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Event introduction
- Participant registration
- Event selection
- Form validation

## How to Run
1. Open this project folder.
2. Double-click `index.html`, or open it in any modern web browser.
3. No server, database, API key, or installation is required.

## Expected Output
Participants can submit their details and immediately receive a registration confirmation.

## Conclusion
This project demonstrates practical use of HTML, CSS, and JavaScript to build a simple, responsive, functional web application suitable for a college mini project.
